# Matches

A match is a competitive event with additional match details. Members can use the list to find upcoming or previous matches. Managers can create, edit, prepare, conclude, and—where eligible—link matches to competition fixtures.

## Create a match (manager)

<Steps>

### Open Matches

Select **Matches** in the active workspace and start a new match. From
**All games**, choose the target game when prompted; the match is then created
only in that game.

### Set the essential information

Enter a clear match name, meeting and game schedule, and the map/mode/side
information your team needs. Hell Let Loose: Vietnam follows the HLL match-data
shape. Wardogs is prepared as its own game scope; its detailed map/cap catalog
will expand when final game data is available.

### Prepare the match

Attach topic presets, stratmaps, and a roster as needed. These are separate resources, so check each one rather than assuming that creating a match creates them automatically. A match creates a Discord forum post by default when the bot and forum category are configured; disable that event option if you do not want one. Use the optional registration announcement start when the match should appear in calendars before its Discord registration message and forum post are published.

### Record the outcome

After play, enter the result and conclude the event when your workflow is complete.

</Steps>

## Competition links

Eligible matches can be connected to competition information. The match must satisfy the available matching context; select the correct event and opponent carefully. Linking a match does not replace the organiser’s official competition rules or results process.

<Callout type="info">
    If a fixture is not offered for linking, check that the workspace, map
    details, schedule, and competition data are correct. It may simply not be an
    eligible match.
</Callout>

## Result, conclusion, and scoring are separate

Recording a match result stores the result and can update a linked competition
fixture. Concluding the match changes its lifecycle, removes its Discord event
messages, completes or cancels its linked Discord scheduled event, and triggers
the one-time score calculation. The calculation uses the workspace score
settings, roster position, manager-confirmed attendance, decline status, and
absence notices; it does not infer attendance from merely signing up or
acknowledging a reminder.

When a recorded result includes linked roster-player statistics, opted-in
rostered players receive a personal match recap by Discord DM. The recap uses
the workspace's configured clan language and opens the matching localized
public-statistics page. Its comparison uses the same previously recorded player
matches shown on that page.

## Review a result (manager)

On a concluded match, open **Review result**. Choose a collected HLL session,
load an existing imported result, or enter scores manually. Selecting a source
does not approve it. Save a provisional version, check the displayed scores and
then confirm that version. Unsaved changes must be saved before confirmation.
An empty score is unknown; zero is a known score.

The form supports two to sixteen participants, including manual Wardogs factions.
Current Wardogs collection supplies server status, not match history. HLL source
candidates are the fifty most recently fetched sessions. A changed or incomplete
source cannot be confirmed; refresh, select the current source and review again.

After confirmation, use **Save reviewed correction** with a reason. The previous
version remains in the recent revision history with its reviewer and timestamp.
A later import does not silently replace a reviewed result. Another manager's
concurrent save requires you to refresh before saving your version.

Player attribution uses active verified Steam links at review time. Manually
entered IDs and player names do not verify an account. Unlinking affects future
reviews; it does not rewrite past review history. Counts do not establish team
membership, attendance or game ownership.

Reviewed results are separate from the legacy imported scoreboard, competition
fixture finalization and event conclusion described above. A confirmed result
does not automatically publish anything on an external website.

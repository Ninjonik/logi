# Welcome to the Logi Wiki

Logi helps Hell Let Loose communities organise events, build rosters, share briefings, and keep Discord coordination in one place. This guide explains what people see, what each choice does, and when a feature is available.

<Callout type="info">
    You can read this wiki without an account. Creating, changing, or managing
    community information requires the appropriate dashboard access.
</Callout>

## A quick map of Logi

| Area             | Who it is for        | What it does                                                                               |
| ---------------- | -------------------- | ------------------------------------------------------------------------------------------ |
| Public site      | Anyone               | Browse communities, clans, competitions, player profiles, and published match information. |
| Dashboard        | Signed-in users      | Select a server workspace and see the information available to you.                        |
| Server workspace | Members and managers | View events, rosters, articles, calendars, and server-specific information.                |
| Manager tools    | Server managers      | Create events, manage members, configure Discord-connected features, and publish rosters.  |

## Before you begin

1. Sign in with the Discord account you use in the community.
2. Open **Dashboard** and choose a server workspace.
3. If a page or action is missing, ask a server administrator. Logi only shows management controls to authorised people.

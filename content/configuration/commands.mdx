# Discord commands

Logi's bot offers eight slash commands in every Discord server it is in. Every
reply is in the **clan language** from **Settings → Channels and language**,
whatever language a member's Discord app uses. The command names stay the
same everywhere; their descriptions and options are shown in the clan
language.

Managers configure the commands in **Settings → Discord → Commands**.

## The commands

| Command                               | What it does                                                                                      | Who may use it by default                                 |
| ------------------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| `/help`                               | A private list of the commands you can use here, with the channels to use and a link to this page | Everyone; each person sees only the commands they may use |
| `/stats`                              | Your player statistics for Hell Let Loose or Wardogs, privately, with **Share**                   | Everyone                                                  |
| `/player`                             | A clan player's profile from the clan's imported matches, privately, with **Share**               | Everyone                                                  |
| `/link`                               | Manage the platform IDs you claimed for Logi                                                      | Everyone, applicants included                             |
| `/notice`                             | Tell the match leads you will come later, for an event you signed up to that has not started      | Everyone signed up for an upcoming event                  |
| `/server-status`                      | The stored state of the clan's game servers for one game (at most five)                           | Logi managers                                             |
| `/close_ticket [reason]`              | Close the ticket thread you are in                                                                | The category's support roles or Logi managers             |
| `/close_application outcome [reason]` | Decide and close the application thread you are in                                                | The category's support roles or Logi managers             |

**Logi managers** are members with Discord's Administrator permission or the
managers' role from **Settings → Roles and access**. **Clan members** have the
clan role from the same page.

Every command is visible to everyone in Discord's command menu. Whether a
person may use it is checked when they use it, freshly from Discord, so a role
removed a moment ago no longer counts. Whoever may not use a command gets a
short private explanation of who may, and `/help` does not offer it to them.

## Replies

Command replies are private: only the person who used the command sees them.
`/stats` and `/player` can offer **Share**:

- `/stats` shares to the channel picked in the command, else to the **Channel
  for Share** on the Commands page, else the bot asks where.
- `/player` shares to the channel where the command was used.

Shared cards name who shared them and have no buttons. Both the person and the
bot must be able to see the channel, send messages there (in a thread: send
messages in threads) and embed links. If not, the private card says the channel
cannot be used now and offers another choice.

`/notice` opens a short window: **Running late** with the match name, a note
that only the match leads see it, and **When will you arrive and why?** (up to
500 characters). After saving, the private confirmation quotes the reason and
attendance reminders for that match stop. A later notice replaces the earlier
one. The **Running late** button in attendance reminders opens the same window,
also from a direct message.

## Configure the commands

**Settings → Discord → Commands** shows:

1. **Command registration**: when the bot last registered the commands in this
   server and how many. **Register again** asks the bot to do it within a
   minute; use it when a command is missing in Discord.
2. **Commands**, split into commands for members and for managers. Each
   configurable command has:
    - an on/off switch;
    - **Who may use it**: everyone in the server, clan members or Logi
      managers, plus extra roles on top of a group;
    - **Reply** (`/stats`, `/player`): only the author, or only the author with
      a **Share** button;
    - **Where it works**: all channels or selected channels only (a thread
      counts as its parent channel). Elsewhere the bot says where the command
      works.

    `/help`, `/link` and `/notice` are always open to everyone. `/server-status`
    is for Logi managers, with optional extra roles, and always replies
    privately. `/close_ticket` and `/close_application` follow the
    **Tickets** and **Membership** settings and work only in their threads.

3. **/stats**: the games it answers for with their data source (public HLL
   Records profiles by Steam account; Wardogs games stored from your game
   servers), the **Channel for Share**, and a preview of the reply with
   example numbers.
4. **Command descriptions in Discord**: what members see in the command menu,
   in the clan language. A command only Logi managers may use gets "(managers)".
5. **Old stats server connections**, when the clan still has some. Only the
   player search in `/link` and in the clan application uses them; `/stats`
   does not. **Move to Game servers** copies them to **Settings → Game
   servers** with the key stored encrypted, untested and stopped; test them
   there, then remove the old connections.

A bar at the bottom counts unsaved changes. After **Save** the bot registers the
commands again by itself; Discord shows the change within a minute.

## When the bot registers commands

The bot registers the commands for each server when it starts, when it is added
to a server, and after the clan language or the command settings change. A
server without Logi gets the commands in its Discord community language, and
`/help` there explains that Logi is not set up yet.

<Callout type="info">
    The bot needs the `applications.commands` scope in the server. If
    registration fails, the Commands page shows why: Discord refused it, limited
    requests or did not answer.
</Callout>

## API

The command settings are part of `GET/PATCH /api/v1/clan/settings` as the
`commands` slice: per command `enabled`, `audience`, `roleIds`, `reply` and
`channelIds`, plus the `/stats` games and sharing channel. **Register again**
and **Move to Game servers** are dashboard-only: one is a live Discord action,
the other handles provider keys.

# Tickets

The **Tickets** page is a server-manager configuration area for ticket-related workflow. It is not a public help desk by itself; it controls how the selected server’s ticket integration behaves.

## Before enabling or changing tickets

Confirm the community’s process: who receives requests, which Discord channels and roles are appropriate, and what information members should provide. Then use the ticket settings form to reflect that agreed process.

## Test the complete path

After changing ticket settings, test with a safe account or a controlled example. Confirm that the request reaches the intended place and that no private information is exposed to an unintended audience.

<Callout type="warning">
    Ticket configuration can change how private member requests are routed.
    Review permission and channel choices with a server owner before making
    broad changes.
</Callout>

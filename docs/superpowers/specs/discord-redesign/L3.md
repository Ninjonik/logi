## 1. Elements

### 1.0 Board-wide rules

- L3-01 · Every panel uses one frame with an "Aktualizováno …" footer, the clan language and the clan accent bar.
- L3-02 · Live score and server status are one panel kind; server status is live score with the score switched off.
- L3-03 · Only a panel with an admin-set custom colour has a different bar; pause and outage are shown by a chip.
- L3-04 · Teams as short code or logo, factions with their emblem, identically in results, live score and league.
- L3-05 · Reporting a player is fully private and in the clan language; every private reply ends with "Tuto zprávu vidíte jen vy · Zavřít zprávu".

### 1.1 Jeden rám pro všechny panely

- L3-06 · Panels are messages the bot keeps in a channel and edits itself (calendar, competition table, results, live score, league); a change never posts a new message.
- L3-07 · Frame header: small label "DRUH PANELU · HRA", title "Název panelu", state chip "Stav" with a short state text; an image on the right only when it carries information (e.g. the map).
- L3-08 · Content: only what the panel shows; long lists go to a private paginated reply.
- L3-09 · Buttons: at most one primary ("Hlavní akce", blurple), the rest grey ("Další akce"), outbound links grey with an arrow ("Odkaz ven ↗"); a panel without actions has no buttons.
- L3-10 · Footer "Aktualizováno před 2 min · Spravováno v Logi" (Discord relative time, ticking by itself); when data fail, a "Pozastaveno" chip says since when, and the bar stays.
- L3-11 · Bar = clan colour, default `#E8A33D`; a panel may set its own colour; state or outage never changes the bar.

## 2. Behaviour and data

- L3-B01 · Panels are managed messages edited in place; deletion of the message re-creates it.
- L3-B02 · Bar = clan accent unless the panel sets a custom colour; state/outage never changes the bar.
- L3-B03 · Footer always shows relative "Aktualizováno" and, for live panels, the refresh interval.
- L3-B04 · Live panel refresh is fixed at 60 s (owner decision; the board's 30 s / 5 min examples are superseded).
- L3-B05 · Results: one card per confirmed result; a correction edits it and shows the previous score; compact look is a panel option.
- L3-B06 · Competition table: one message per division, updated after every confirmed result, points by the competition rule.
- L3-B07 · Calendar entries filtered by categories chosen in settings; titles link to the Discord announcement.
- L3-B08 · Private player list: 8 per page, current round only, killed/deaths (HLL) or kills/money (Wardogs).
- L3-B09 · Reports: max 3 open per reporter; private thread visible to reporter and staff; staff pinged; closed with `/close_ticket`.
- L3-B10 · Live panel shows teams when a Logi match is running on that server.
- L3-B11 · When data fail the panel shows "Pozastaveno"/"Nedostupný" with the last data time.

## 3. Owner decisions applied

- **Refresh every 60 s** for all live panels (P4); the board's "30 s" and "5 min" footers are not used.
- **WD League per-fixture cards (L3-50..57): SUPERSEDED** by P6 (two self-updating panels covering all fixtures plus recent results). Not to be implemented as cards.
- **Results not backfilled (L3-25): SUPERSEDED** by P6 (backfill the last 5 on creation, one results panel per game).
- **Live score / server status (L3-33..49)**: frame, chips and data follow P4; graphics style default **A (generated image)** per P7/P8; the text frame here remains the text under the image.
- SEED never appears on public panels (P5).

## 2. Behaviour and data

- P8-B01 · Clan-wide default panel style (A/B/C), default **A**; per-panel override in P2.
- P8-B02 · One banner per server (game-data connection): PNG/JPG/WebP, 3:1, ≤2 MB; crop position top/centre/bottom; "use map image when banner missing" switch; per-server bar colour with reset to clan colour.
- P8-B03 · Map image catalogue: built-in Logi images per map (HLL and Wardogs), clan overrides (PNG/JPG/WebP square ≥160×160, ≤2 MB), restore default; maps without image can get one; search and game filter.
- P8-B04 · Fixed icon set: 8 HLL nation/side icons + 4 Wardogs icons = 12; 7 status/gauge emoji; uploaded automatically by the bot as application emoji; upload state shown.
- P8-B05 · Saved changes take effect on the next panel refresh (≤60 s); new file names per version.
- P8-B06 · The old per-panel faction emoji override is replaced by the fixed set / clan-wide signs (N1-55).
- P8-B07 · `/api/v1`: graphics settings (style default, map/banner references) are exposed in `GET/PATCH clan/settings` with OpenAPI; binary uploads are a documented exclusion — the API references existing assets (spec `docs/superpowers/specs/2026-10-05-discord-redesign-design.md`).

## 2. Behaviour and data

- P2-B01 · One editor page per panel; types live server, Naše servery, Výsledky, WD League, Kalendář; type locked after the first send.
- P2-B02 · Channel verification lists each required permission and whether @everyone can view the channel; missing Attach Files → text-only panel.
- P2-B03 · Server password: allowed only in a channel @everyone cannot view; stored encrypted; re-checked on every refresh and removed automatically if the channel becomes public (P4).
- P2-B04 · IP:port comes from Herní servery; Wardogs join code entered per server; "Připojit se" button only for HLL, via `logi.app/join/<server>`.
- P2-B05 · "Nahlásit hráče" requires a ticket category; channel and support are set in Tickety.
- P2-B06 · Per-panel title and description; banner (PNG/JPEG/WebP ≤2 MiB) replaces the map image.
- P2-B07 · Bar colour defaults to the clan colour; custom per panel.
- P2-B08 · Refresh fixed at 60 s for all panels; footer timing line optional.
- P2-B09 · Preview rendered from real server data with the same renderer as the bot.
- P2-B10 · "Načíst data ze serveru" runs the bot's read from the dashboard (HLL and Warcon), showing status, players, freshness and warnings.
- P2-B11 · Delivery timeline (saved → bot claimed → sent → last refresh/next), last error and uncertain-delivery recovery ("Zkusit znovu"); the page polls itself.
- P2-B12 · Actions: Uložit (edits the existing message), Odeslat do kanálu, Obnovit teď, Pozastavit, Odstranit zprávu.
- P2-B13 · Naše servery: selected servers in drag order, per-server chips (Živě, Seed běží, Starší data), one join button per HLL server; public info only unless the channel is private.
- P2-B14 · Provider limits (Warcon 429): keep last data, retry with backoff, advice after one hour.
- P2-B15 · WD League panel: toggles for table / fixtures / recent results and the fixture count; produces two messages.
- P2-B16 · Panel style A/B/C per panel overriding the clan default (P7/P8; default A).

## 3. Owner decisions applied

- Editor with real-data preview, test fetch, post now, refresh, pause, delete and retry (DECISIONS).
- One panel per server; Naše servery optional; refresh 60 s.
- Private training panel shows the password only in a channel @everyone cannot see; hidden automatically if the channel becomes public.
- Joining: IP:port (HLL) and join code (WD), "Připojit se" through `logi.app/join`.
- SEED button never on the panel; only progress (Varianta B of the seed question; A and C "varianta, nevybráno").
- WD League = two self-updating panels; per-fixture cards end.
- **Panel style default A (generated image)**; the editor can switch one panel's style (P7/P8).

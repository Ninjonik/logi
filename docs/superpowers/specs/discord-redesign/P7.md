## 2. Behaviour and data

- P7-B01 · Panel style per panel: A (default for HLL and Wardogs), B, C; clan default set in P8, per-panel override in P2.
- P7-B02 · Style A: server-side PNG 1200×400 rendered from the same live data; re-rendered at most once per 60 s and only when content changes; unique file name per version; the text summary is always present under the image.
- P7-B03 · Application emoji set (12 faction/nation signs + 7 status/gauge pieces) provisioned automatically by the bot (no manual script) and reused everywhere.
- P7-B04 · Map image resolution: clan override → Logi built-in → none; banner falls back to the current map image when "use map image" is on (P8).
- P7-B05 · "Nová mapa" chip shown for 5 minutes after a map change; banner/thumbnail swap; score image background changes.
- P7-B06 · At most 10 attachments per message.
- P7-B07 · Wardogs: leading faction drawn in the clan colour; faction points as bars.
- P7-B08 · Style B: per-server bar colour (from P8).
- P7-B09 · Combined panel: one section per server with map thumbnail; join buttons at the bottom row (max 5 per row).
- P7-B10 · HLL nation detection from server data (layer/map → nations); generic Spojenci/Osa sign when unknown.

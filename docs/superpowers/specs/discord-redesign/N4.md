## 2. Behaviour and data

- N4-B01 · Application settings: enabled, panel channel, thread parent, title, text, image, welcome text, post-submit switches, 24 h draft TTL, web-form switch (default off).
- N4-B02 · Form schema: windows (fixed windows 1 and 2, clan-question windows 3, 3b…), each ≤5 fields; question types short text, long text, select, multi-select, yes/no, number; per-question required, label ≤45, help ≤100, placeholder, options ≤25, min/max selections, game filter, category filter.
- N4-B03 · Field count per window is computed for the applicant who sees the most questions; adding beyond 5 is blocked with "Přidat okno".
- N4-B04 · "Vyžadovat ověřený Steam" (HLL): the bot sends the web verification link before window 2 and disables manual Steam ID.
- N4-B05 · Per-category "Ptát se na specializaci" (HLL only; disabled for Wardogs categories).
- N4-B06 · Decision buttons apply role changes per table (N4-40) and send result + DM; permission = category support or Logi admins.
- N4-B07 · Saving re-renders the panel in `#nabor` automatically.
- N4-B08 · Channel checks shown inline (bot can post/attach in panel channel; can create private threads in parent).
- N4-B09 · `/api/v1` parity for membership settings, including the application form schema and web-form switch: exposed in `GET/PATCH clan/settings` with OpenAPI (spec `docs/superpowers/specs/2026-10-05-discord-redesign-design.md`); application decisions are a documented exclusion (Discord-thread actions).

## 3. Owner decisions applied

- **Discord windows are the default**; **Varianta B (web form) is "varianta, nevybráno" by default — available behind the switch N4-42, off**.
- One form in several windows, submitted at the end; thread after submit.
- Decision buttons: DECISIONS lists "accept as člen, rekrut or žoldák, or reject with a reason". N4-39/40/41 show only člen/rekrut/reject and leave Čeká and Žoldák to `/close_application`. **Resolved by the spec `docs/superpowers/specs/2026-10-05-discord-redesign-design.md`:** all five buttons (člen, rekrut, žoldák, "Zamítnout…", "Ještě nerozhodnuto") as in L6; the N4 preview (N4-39) and decision table (N4-40) must list the žoldák and "Ještě nerozhodnuto" rows too, and N4-41's note changes to "`/close_application` keeps working".

## 1. Elements

### 1.0 Board-wide rules

- P5-01 · When a server is empty or below the threshold an admin starts a seed; a call is posted to `#seed` pinging the Seed role; the server panel shows progress; at 40 players both switch to "Živě".
- P5-02 · Seeds are started only by admins: in `#spravci` or in Logi; the public panel has no button.
- P5-03 · The Seed role is pinged once per seed; edits ping nobody.
- P5-04 · At least 2 hours between seeds.
- P5-05 · Everyone turns the Seed role on/off themselves with the button "Zvát mě na seed"; private replies end with "Tuto zprávu vidíte jen vy · Zavřít zprávu".

## 2. Behaviour and data

- P5-B01 · Seed lifecycle: start (admin button / web / plan) → post call in seed channel with one Seed-role ping → edit every 60 s with progress → at ≥40 players edit to "Server je živý" (remove ping line, hide role button) → or admin ends early ("Seed ukončen").
- P5-B02 · Cooldown of at least 2 h between seeds; the refusal names the next allowed time.
- P5-B03 · Seed role is opt-in, toggled by a button on the pinned intro and on every call; manual role assignment also counts.
- P5-B04 · Seeders = players who joined during the seed; the final card thanks them with a count and the seed duration.
- P5-B05 · Public server panel mirrors the seed state (chip, progress, "Otevřít výzvu") from the same data.
- P5-B06 · Admin control messages: one per server in a private channel; "Spustit seed"/"Ukončit seed", "Obnovit panel", "Pozastavit panel"/"Pokračovat"; fresh admin-role check on each click; private replies.
- P5-B07 · Progress bar: 10 segments towards the live threshold (40).

## 3. Owner decisions applied

- **SEED is for admins only**: "Ovládání serveru" in a private admin channel + Logi web; no seed button on the public panel. Seed question variants: **B chosen**; A (button on public panel) and C (web only) are "varianta, nevybráno".
- Posts to the seed channel and tags the opt-in Seed role; cooldown between seeds; edits the call to "Server je živý" at the threshold; live at 40, seed starts under 20.
- **Conflicts with P3 to confirm** (INDEX): cooldown 2 h (P5) vs ping protection 4 h (P3); role button "Zvát mě na seed" (P5) vs "Odebírat výzvy" (P3); one control message per server (P5) vs one message for all servers (P3).

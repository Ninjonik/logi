## 1. Elements

### 1.0 Board-wide rules

- L2-01 · Every DM uses the same card as channel messages (V2, clan accent), in the clan language.
- L2-02 · Reminders always carry the weekday, e.g. "ne 11. 10. · sraz 19:30 · start 20:00".
- L2-03 · No server password in any DM; the player finds it under "Zobrazit zařazení".
- L2-04 · Buttons work inside the DM (modals have a close button "Zavřít"); the reply arrives in the same conversation, without the "Tuto zprávu vidíte jen vy" line.
- L2-05 · Every DM ends with the footer "Klan Vlci · Nastavit zprávy"; the link opens Můj účet → "Zprávy od bota".

## 2. Behaviour and data

- L2-B01 · All DMs: V2 card, clan accent, clan language, "ty", footer with clan name and settings link.
- L2-B02 · No password in any DM.
- L2-B03 · DM buttons reply as normal DM messages (not ephemeral).
- L2-B04 · Sign-up reminder: daily from day 2 after the announcement until sign-ups close; only members in template statuses who have not answered.
- L2-B05 · Attendance reminder: offsets per match from {24, 18, 12, 6} h before the meeting; title "Dnes/Zítra hraješ"; weekday always shown.
- L2-B06 · Manual reminders include "Připomínku poslalo velení z Logi." and use the clan accent.
- L2-B07 · Confirm/late/decline after the match start are refused with "Zápas už začal".
- L2-B08 · A late or absence notice stops further attendance reminders for that match; decline frees the place for reserves.
- L2-B09 · Roster change DMs are bot-sent, one per affected player, combining move and role changes.
- L2-B10 · Recap: only linked and opted-in players; toggling edits the same DM; opt-out applies across all the user's clans.
- L2-B11 · Numbers use the clan locale (decimal comma for cs).
- L2-B12 · Training result DM to each evaluated participant, pass or fail.
- L2-B13 · Decision DMs write roles without mentions (Discord cannot render them outside the guild).
- L2-B14 · DM delivery failures are reported where the admin acted (match page, publish dialog), per player.

## 3. Owner decisions applied

- Clan language, "ty", one clan accent for all DMs.
- Late/absent notices to the match thread are optional and off by default (L5/N1); this board only covers the DM replies.

## 2. Behaviour and data

- P1-B01 · Panel states: Zveřejněno, Chyba, Čeká na bota, Neodesláno, Pozastaveno — shown for every panel, including before the bot's first claim.
- P1-B02 · Per panel timing: last update / last attempt, next refresh / next retry, saved-at for unsent panels.
- P1-B03 · Specific error cause with fix steps (e.g. missing permission name) and a retry action.
- P1-B04 · Actions: "Obnovit teď" (force a refresh), "Pozastavit"/"Pokračovat", "Zkusit znovu", "Odeslat do kanálu", "Opravit" (→ editor), "Otevřít zprávu".
- P1-B05 · Bot heartbeat with version and last contact; warnings for offline (stale contact) and outdated version (minimum version).
- P1-B06 · Refresh interval fixed at 60 s for all panels.
- P1-B07 · Data sources list collection state, last data age and live-read check per source.
- P1-B08 · Panel types listed: live server per server, Naše servery, Ovládání serveru, Výsledky (one per game), WD League (two messages), Kalendář.
- P1-B09 · The page polls status while open (status changes without reload, e.g. "bot ho převezme do 15 s").
- P1-B10 · `/api/v1`: panel settings are exposed in `GET/PATCH clan/settings` with OpenAPI; live Discord actions (post now, refresh, pause, delete, retry) are a documented exclusion in `docs/integrations/website/configuration-coverage.md` (spec `docs/superpowers/specs/2026-10-05-discord-redesign-design.md`).

## 3. Owner decisions applied

- New Logi page "Panely v Discordu" with list + status, editor (P2), bot heartbeat with version (DECISIONS).
- One panel per server (Vlci #1 public, Vlci #2 private clan channel) + optional "Naše servery".
- Refresh every 60 s.
- SEED only for admins via "Ovládání serveru" in a private admin channel and the web (Varianta B of the seed question; A and C "varianta, nevybráno").
- WD League = two self-updating panels in `#liga` (tabulka + nejbližší zápasy with recent results).
- Results: one panel per game. Note: P1-19 says "posílá jen potvrzené od 1. 10."; the spec `docs/superpowers/specs/2026-10-05-discord-redesign-design.md` and P6 decide a backfill of the last 5 confirmed results on creation, so P1-19's sub-line must describe that instead.

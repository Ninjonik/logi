## Fix list (by importance)

1. **D5-08 single-channel mode.** When the clan has no roster channel, either hide "Označit zařazené hráče" in `src/components/app/roster-publish-dialog.tsx:570-582` (use `context.rosterChannelName`/a flag from `roster-publish-context.ts`) or apply `roster.discordMentionPlayers` to the announcement that doubles as the roster (`discord-bot/src/events/announcement.ts` `announcementMessage`, first roster post only).
2. **D5-B04 server-side baseline.** Store the published squad places when a roster is published (e.g. on `convex/rosters.ts` upsert, `published: true`) and let `convex/rosterChanges.ts:request` use that snapshot as `before` instead of the browser-sent `previousRoster`.
3. **D5-13 / D5-14 date wording.** Use a relative day ("dnes", "včera") and "v" for the published time in `formatShortDateTime` / `t.publishedAt` / `t.changesAgainst` (`roster-publish-dialog.tsx:103-124`, `cs.ts:6168,6213` and en/de).
4. **D5-21.** Either record in INDEX that the D5 preview shows the L1 digest, or add the "Hráči se změnou dostali DM" note to the digest footer when DMs were sent (L1-124 would then need the same decision).

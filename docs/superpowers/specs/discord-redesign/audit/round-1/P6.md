Both League messages are implemented, wired and rendered by the bot's real `runPanel` → `runLeaguePanels`:
- the bot worker passes `league` ports (`discord-bot/src/public-panels/worker.ts:334-350`);
- the Convex query is `leagueDiscoveryPanels:forGuild`;
- a cron collects every League fixture each minute (`convex/crons.ts:88-93`).

With synthetic results, the table matches the board: a code block, the "›" marker with ANSI bold, the legend, the button and the footer. The fixtures message shows teams, nations, members, faction emoji, the map line with thumbnail, preparation chips, links, the 4000-character fitting with "… a další zápas na webu ligy", and the recent podiums.

The results panels are keyed by game, limited to one per game, backfill the last 5 results oldest first, and edit on correction.

Gaps:
- the results parser is still blocked (recorded);
- at runtime the "Poslední výsledky" section therefore always claims there were no results;
- some small copy and format differences.

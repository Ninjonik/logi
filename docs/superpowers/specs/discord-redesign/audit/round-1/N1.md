## Fix list (by importance)

1. **Feed the "Panely" group from the P1 overview (N1-30, N1-31, N1-32, N1-34, N1-35, N1-36, N1-45a, N1-B08).**
   - In `src/components/app/settings/discord-messages-settings.tsx:147-217`, read `GET /api/servers/{id}/discord-panels` (`discordPanels:overview`) instead of `/discord-public-panels`.
   - Rebuild `src/components/app/settings/messages/panel-overview.ts` on `PanelOverviewItem`:
     - every kind: `server`, `servers`, `results` per game, `league`, `calendar`, `competition`;
     - `state` for the chip, including "Čeká na bota";
     - `panelErrorText(error).title` for the error line, which gives the board's short sentence;
     - `title`;
     - `channelPrivate && settings.content.password && servers[].hasPassword` for "ukazuje i heslo serveru";
     - `settings.calendarCategories` mapped to category labels, and "pozastavil {people[pausedBy]}".
   - The switch names "Panel Naše servery", "Panel Výsledky HLL" and "Panely WD League" come with the rows.
   - `convex/discordPublicPanels.ts:183-253` (`list`) can then be retired or kept only for the report category.
2. **Use the real builders for the previews (N1-08, N1-B07).** In `src/domain/discord-messages/settings-previews.ts`:
   - `announcementPreview` (327-400) → `buildAnnouncementView`;
   - recruitment, application, ticket and player-report cases (678-890) → `applicationPanelView`, `applicationCardView`, `applicationDecisionDmView`, `ticketPanelView`, `ticketOpenedView`, `ticketClosedDmView` and `report-views.ts`, fed with the clan's real ticket and membership settings where available.
3. **Results copy (N1-34).** Align `messagesPage.panels.resultsDetail` in cs, en and de with the backfill decision ("po vytvoření pošle posledních 5 potvrzených"); the P1 list already says this.
4. **Robustness.** When only panel switches changed, skip `POST /discord-settings {}` in `discord-messages-settings.tsx` `save()`. The route always fetches the Discord channel list, so a Discord outage would stop the pause or resume from being sent.

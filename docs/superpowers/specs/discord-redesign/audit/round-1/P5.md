# Audit P5 · DcSeedMessages (Seed v Discordu)

Auditor: independent audit, worktree at `feat/valkyria-integration` = `e5d860f`. No product code changed. The binding resolution applies (INDEX, "Resolutions" #1):
- 2 h between seed starts, plus at most 1 role ping per 4 h;
- the button reads "Zvát mě na seed";
- one "Ovládání serveru" message per server;
- the call title includes the server's full name ("Seedujeme Vlci #1 · Public").

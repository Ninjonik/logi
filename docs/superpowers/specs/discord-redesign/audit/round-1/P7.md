**Headline:** the style A image is real and board-faithful. It was rendered for HLL and Wardogs through the actual HTTP route `POST /api/discord/panel-image` (dev server, internal secret; a wrong secret gives 401) and through `src/lib/panel-image/render.ts`. It is near pixel-identical to the board; see `compare-styleA-hll.png` and `compare-styleA-wd.png`.

Styles B and C are selectable per **server** panel and are rendered by the bot:
- editor radio: `src/components/app/discord-panels/editor-steps.tsx:1513,1737-1790`;
- Convex validator: `convex/discordPublicationTable.ts:19-50`;
- bot: `discord-bot/src/public-panels/panel-runner.ts:479`.

This was verified end-to-end by running the bot's real `runPanel` with fake Discord/Convex ports. Panel style a/b/c and the clan default (A, and C) each produce the expected payload and attachments.

The deviations are mostly **card structure around the image**: the header sits above the image or banner instead of the image or banner being on top, and style C is not the one-line compact form. There are also two functional gaps:
- the combined "Naše servery" panel ignores the style, never draws a banner and has no gauge or signs per row;
- the "Použít obrázek mapy, když banner chybí" switch is ignored by the bot for the style B banner.

## Fix list (by importance)

1. **The `useMapImage` switch is ignored for the style B banner** (P7-B04, also P8-10 and P8-B02).
   - Where: `discord-bot/src/public-panels/panel-runner.ts:564-575`.
   - Fix: when `graphicsServer.banner.useMapImage === false` and there is no server banner `publicId`, pass `background: null` to the banner model. Also skip the `mapImage(…, "banner")` fallback. The score image may keep the map background, as P8-14 intends.
   - Test: add a runner test for "switch off → banner without map".
2. **The combined panel ignores the style** (P7-19).
   - Where: `panel-runner.ts:830` passes `banner: null`, and `editor-steps.tsx:1513` limits the style to `kind === "server"`.
   - Fix: allow a style for `servers` panels. In style B, render a banner image with subtitle "Naše servery · Hell Let Loose a Wardogs".
   - Fix: add per-row sign and gauge lines in `src/domain/discord-publications/combined-panel.ts` `rowText`, using `playerGaugeEmoji` and `hllSideSign`/`wardogsSign`, as on P7-19.
3. **The header sits above the image in style A and the banner in style B** (P7-03, 07, 08, 13, 16, 18).
   - Where: in `src/domain/discord-publications/live-panel.ts:847`, `panelFrame` always puts label/title/state first.
   - Fix: for style A, put the gallery first and drop the label/title, which the image already shows. Keep the chip+detail line under the image.
   - Fix: for style B, put the banner gallery first, then label/title with the thumbnail.
   - Also: drop the mode from the next map in the style A summary (`nextMapText` → name + lighting), remove the sign emoji from that summary, and avoid repeating "Zestafona" for Wardogs.
4. **Style C compact layout** (P7-11).
   - Fix: build a dedicated style C view. One section line "status-icon **Title** Game · Map · Mode · Light"; then "★ Spojenci 3 : 2 Osa ✚ · zbývá N min"; then the gauge.
   - Fix: leave out the address line and the "Nahlásit hráče" button, keeping only "Připojit se" and "Zobrazit hráče".
5. **"Připojit: Vlci WD" on the combined panel** (P7-20).
   - Where: `combined-panel.ts:166-172`.
   - The single-server WD panel already offers "Připojit se" through `/join/<slug>`. Get an owner decision on P2-39 vs P7-20/P4-38, then make the two panels consistent.
6. **Clan badge** (P7-13, P7-18, P8-07). The bot (`panel-runner.ts:554-558`) and the dashboard (`clanBadgeTag` in `src/domain/discord-publications/panel-graphics-settings.ts:293`) derive the tag differently for multi-word names. Use `clanBadgeTag` in the bot too, and consider a real clan tag setting so the board's "VLK" is possible.

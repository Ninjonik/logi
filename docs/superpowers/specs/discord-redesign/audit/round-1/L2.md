- one missing settings anchor;
- automatic reminders whose failed DMs are not recorded;
- the two "Přijdu později" forms, which differ;
- recurring cosmetic differences: the divider above the footer is missing, and stat tiles become one line because of a V2 limit.

## Fix list (by importance)

1. **L2-64, scheduled reminders.** Failed DMs are invisible. In `discord-bot/src/sync/signup-reminders.ts:131-152` and `discord-bot/src/sync/attendance-reminders.ts:220-245`, collect the failed user IDs and store them as an outcome the match page can show. `eventReminders` with an "automatic" audience would do, and `src/lib/read-models/reminder-delivery.ts` would read it. Otherwise record an explicit owner exclusion.
2. **L2-32, two "Přijdu později" windows.** Get the owner's choice between L2-30 and M3-16 copy. Then have `attendance-replies.ts:225-256` open `buildNoticeModal` (`commands/notice.ts:80-104`), or the other way round, so one window and one confirmation exist.
3. **L2-05, application DM settings link.** Replace the three hand-built URLs with `dmSettingsUrl(config.defaultLanguage)` (`discord-bot/src/events/match-context.ts:115`):
   - `membership-decision.ts:264`
   - `membership-application.ts:403`
   - `membership-web-submissions.ts:89`
4. **L2-03 risk (owner decision).** "Zobrazit zařazení" clicked in a DM posts the server password into the DM. Consider an ephemeral reply, or dropping the password for DM clicks, in `roster-assignment.ts:239-260`.
5. **Cosmetic dividers (L2-28, 29, 31, 34, 52, 54, 56).** Add `{ kind: "separator", divider: true, spacing: "small" }` before the DM footer:
   - in `reply()` (`direct-message-views.ts:308-319`);
   - in `trainingResultView` (`:786-802`);
   - before the button in `applicationDecisionDmView` (`application-views.ts:1269-1280`);
   - in `ticketClosedDmView`, before the button instead of after it (`ticket-views.ts:417-428`).
6. **L2-57.** Deep-link "Otevřít tým v Logi" to the team, or record that it opens the filtered Týmy list (`team-request-notifications.ts:44-61`).
7. **L2-45.** Platform limit (no tiles in V2). Record it as accepted.

- Focused tests: 142/142 pass (`match-announcement`, `match-attendees`, `match-signup-replies`, `roster-message`, `match-forum`, `announcement-state`, `signup-list`, `calendar-link`, `announcement-migration`, `bot/events/*.test.ts`, `roster-change-service`, `roster-assignment`, `roster-publish-dialog`, `roster-update-notifications-route`, `match-messages-settings-slice`). `npm run typecheck`: exit 0.

Platform notes that apply to many rows and are not counted against the item: Discord cannot draw chips, so a chip is a tone emoji + bold label (`dm/message-layout.ts:97-103`); text cannot be coloured (amber "přijde později", green "✓ potvrzeno"); `<t:…:d>` renders the full short date of the reader's locale; Discord adds "(upraveno)", "Tuto zprávu vidíte jen vy · Zavřít zprávu" and the 🔊 icon of a voice-channel mention itself.

The page is complete and close to the board. The one real functional gap is that the switch "Použít obrázek mapy, když banner chybí" is saved and shown, but the bot does not honour it when it is OFF (see P7-B04).

The other differences are small: the saved banner's file name is not shown; the dashboard and the bot derive the clan badge differently; and map overrides and the per-panel banner reach Discord as URLs, not attachments.

## Fix list (by importance)

1. **Honour "Použít obrázek mapy, když banner chybí" = OFF in the bot** (P8-10, P8-B02; the same fix as P7 #1).
   - Where: `discord-bot/src/public-panels/panel-runner.ts:564-575`.
   - Fix: when there is no server banner and `useMapImage` is false, render the style B banner with `background: null` and skip the map-banner fallback. This makes the bot match the page's "Bez banneru je panel bez obrázku nahoře".
2. **One clan-badge rule** (P8-07).
   - Fix: use `clanBadgeTag()` from `src/domain/discord-publications/panel-graphics-settings.ts:293` in `panel-runner.ts:554-558` and in `src/components/app/discord-panels/editor-preview.ts:189`, so the P8 preview, the P2 preview and Discord agree.
   - Optional: a clan tag setting to allow "VLK".
3. **Show the saved banner's file name** (P8-08). Store the original file name with the image asset, for example on `imageAssets` or with the graphics row, and return it from `discordPanelGraphics:get` so "Nahráno vlci-public.png · 1200 × 400 · 380 kB." survives a reload.
4. **Attach map overrides as files** (P8-30), if the board rule is to be followed exactly.
   - Where: `panel-runner.ts:591-597` and `discord-bot/src/league/panels.ts:111-115`.
   - Fix: download the override bytes and attach them like the built-in thumbnails (`mapa-<key>-thumb-<hash>.webp`) instead of linking the public URL.
5. Clean up: remove the unused `factionEmoji*` dictionary keys (`src/i18n/messages/{cs,en,de}.ts`). Optionally enforce or warn about square map images (`src/domain/assets/image-asset.ts` `IMAGE_MIN_SOURCE`).

Output:
  ```
  refresh  HTTP 409 not_sent (draft)
  publish  HTTP 403 forbidden (foreign origin)
  publish  HTTP 202 | worker sees change | chip waiting → bot posts panel:p1 in channel → chip published
  refresh  HTTP 202 | worker sees change | waiting → bot edits → published
  pause    HTTP 202 | worker sees change | paused → bot draws paused card once → paused
  resume   HTTP 202 | worker sees change | waiting → bot edits → published
  retry    HTTP 202 | resetDelivery(abandonPending) | waiting → bot sends → published
  delete   HTTP 202 | worker sees change | waiting → bot publishes channelId=null (deletes) → unsent
  publish  HTTP 202 | worker sees change | waiting → bot posts again → published
  ```

The heartbeat is written every 30 s (`worker.ts:465-479`).

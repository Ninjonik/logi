## Reported deviations checked

1. **Stat tiles shown on one line.** Verified. "Zabití **412** · K/D **1,37** · Výhry **14 / 23**" is one text display (`src/domain/player-stats/stats-reply.ts:221-225,338-342`; `src/domain/discord-commands/player-view.ts:204-215`). **This is a real platform limit.** A Components V2 container stacks text displays, sections (text plus one accessory), galleries, separators and action rows vertically. It has no columns. The only Discord construct with side-by-side values is the legacy embed's inline fields, and an embed cannot be sent in an `IS_COMPONENTS_V2` message. The owner decision is "Components V2 only, no legacy embeds". The three numbers stay side by side in one line, in bold. Justified.
2. **Map artwork and "Obnovit" removed from `/stats`.** Verified, and this is **not a deviation**:
   - The board draws no thumbnail on any `/stats` card.
   - Section "CO SE MĚNÍ PROTI DNEŠKU" (M2-34) explicitly says "„Obnovit“ mizí, každý pohled načte čerstvá data".
   - The old code had `artwork()` and `setThumbnail` (`d659d51:discord-bot/src/interactions/stats.ts:59,209`). The new view has neither. Every view button re-reads the data (`discord-bot/src/interactions/stats.ts:486-497` → `refresh`).

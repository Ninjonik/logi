**Wiring (clicked in the browser, `audit/p1p2n1-actions.cjs`):**
- Načíst data ze serveru → `POST /discord-panels/test-fetch {"connectionId":"c-v1","panelId":"p-v1"}`. On "Naše servery" it sends one request per server (3).
- Ověřit → `POST /discord-panels/channel-check {"channelId":…}`.
- Obnovit teď → `actions {"action":"refresh"}`; Pozastavit → `{"action":"pause"}`.
- Odstranit zprávu → a confirm dialog, then `{"action":"delete"}`.
- Zkusit znovu (stuck box) → `{"action":"retry"}`.
- Odeslat do kanálu (draft, no change) → `{"action":"publish"}`.
- Uložit after a title edit → `POST /discord-panels {"panelId":"p-v1","settings":{…},"send":false,"expectedRevision":5}`. The bar read "1 neuložená změna · Uložení upraví zprávu v #servery, nová se neposílá."

**Route to bot.** See the chain run in `P1.md` (`audit/p1p2-audit-chain.ts`). Every action returns HTTP 202, changes the worker's `panelStateKey`, and the real `runPanel` posts, edits, draws the paused card, resends or deletes accordingly.

**Načíst data ze serveru, end to end:**
1. The route runs `testFetch` (origin and admin checks).
2. The gateway sends `fetchAction("discordPanels:testFetch")`.
3. The action calls `testContext` (internalQuery with `authorizeDashboardAdmin`).
4. It calls `hllLiveData:read` or `warconData:read` with `actor`; both accept a dashboard actor (`hllLiveReads.ts:50-59`, `warconReads.ts:51-80`).
5. `testPanelFetch` runs.
6. The response is the `liveServerPanelView` preview plus `facts`, with the roster IDs removed and no key, address or password.

**Accessible names (verified):**
- the comboboxes "Kanál panelu", "Herní server" and "Kategorie ticketu";
- permission items "Má:/Chybí: …";
- 11 switches named by their labels.

## Fix list (by importance)

1. **Wardogs results panel cannot be created (P2-04, P2-35).** In `takenKinds` (`src/components/app/discord-panels/panel-editor.tsx:147-167`), disable "results" only when every enabled game already has a results panel. When the type is picked, preselect a game that has none (`GameStep`, `editor-steps.tsx:528-575`).
2. **A saved IP:port cannot be edited (P2-15, P2-39, P2-B04).**
   - Always render the address input, prefilled with the saved value, with a clear option: `editor-steps.tsx:1068` and `1311`.
   - Either fill it from the game server connection, or change the help "{address} z Herní servery." so it no longer claims that source.
3. **"Naše servery" data parity (P2-38, P2-43, P2-B09a).** Choose one:
   - give the bot's `runCombined` (`discord-bot/src/public-panels/panel-runner.ts:716-742`) the live facts within the provider budget, so queue, time left and next map appear; or
   - hide "Další mapa" and "Fronta" for combined panels, and draw `combinedPreview` (`src/components/app/discord-panels/editor-preview.ts:294-369`) from `snapshotLiveFacts`, so the preview equals the post.
4. **Preview without Attach Files (P2-B09b).** When the channel check has `attach_files: false`, drop `images.score/banner/thumbnail` in the preview input (`panel-editor.tsx:486-516`).
5. **Past-tense last error (P2-32).** Add a past-tense title for `lastError` (e.g. `discordPanelStatus.errors.<code>.past`, "Discord neodpověděl včas.") and word one minute as "o minutu": `editor-side.tsx:718-731`, `panel-time.ts` `duration`.
6. **Owner sign-off (P2-27, P2-54, P2-55).** Record that the editor preview follows the P4/P6/P7 Discord boards (Warfare/Den, Adresa, the League message copy) as a resolution, like resolution 9. Otherwise align the bot copy with P2.

The core is in place and wired: one live panel per server (`kind: "server"`) and the optional combined panel (`kind: "servers"`), state chips (Živě / Prázdný / Seedujeme / Nedostupný / Pozastaveno, plus "Starší data"), a fixed 60 s refresh, the CRCON queue, next map and day/night when reported, the encrypted password checked against `@everyone` on every pass, the private player list, and the public `/join/<slug>` page that opens `steam://connect`.

The main gap is the **default style A**, a generated image with a short text summary under it. On the default panel, the image plus the text drop several things the P4 frames require:
- the empty-state sentence (and the score is still shown);
- the seed progress bar and seed sentence;
- the running Logi match line;
- "Z KLANU HRAJE".

The full P4 text frames appear only in style B or C, or when the image cannot be rendered. Also:
- The password-hidden notice in the errors channel is a generic, misleading card.
- The combined panel and the join page never show the queue.

## Fix list (by importance)

1. **Style A text under the image loses P4 content.** This is the default panel style. In `src/domain/discord-publications/live-panel.ts:686-695` (the style-A branch of `liveServerPanelView`), keep these state-specific parts of the full card:
   - empty: the sentence, and no score;
   - seeding: the progress bar plus "Seed běží od … Výzva je v #seed";
   - private channel: the match line and "Z KLANU HRAJE".

   Covers P4-16, 17, 18, 23, 25, B07, and P5-15/17/B05.
2. **The score image ignores the panel state and switches.** `liveScoreImageModel` (`src/domain/discord-publications/live-panel-image.ts:21-178`, called at `discord-bot/src/public-panels/panel-runner.ts:517`) always draws the score and leaders. Pass the panel's state and its switches, and hide the score when the server is empty. Also pass the seed target, so the image can show "12 / 40" for a seed.
3. **Password-hidden notice (P4-30, P4-B06).** Give it its own error source and copy in `discord-bot/src/error-reporting.ts` / `src/domain/discord-messages/bot-errors.ts`. Alternatively, post `getPanelMessages(lang).live.passwordHiddenNotice` as its own grey card. Today admins read "Discord akci odmítl · Zkus to znovu".
4. **Combined panel queue and next map (P4-38).** `runCombined` (`panel-runner.ts:700+`) uses snapshots without a queue or next map, so the editor's "Fronta" and "Další mapa" switches for "Naše servery" have no effect. Read them live, or carry them in the snapshot.
5. **Join page queue (P4-44).** Add `queue` to `discordPanelBot:joinPage` (`convex/discordPanelBot.ts:467`), `ServerJoinPage` (`src/lib/read-models/server-join.ts`) and `ServerJoinCard` facts. The board shows "fronta 3" and not the map.

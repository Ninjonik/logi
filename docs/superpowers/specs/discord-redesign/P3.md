## 2. Behaviour and data

- P3-B01 · Seed plan per server: enabled, live threshold (default 40), start threshold (default 20), triggers manual / schedule (days + time) / automatic (below N players within a time window), challenge channel, Seed role, self-service role button, ping protection (max 1 role ping per N hours), message template with `{server}`, `{hráči}`, `{chybí}`, `{hranice}`, end action (edit to "Server je živý" or delete), max duration.
- P3-B02 · Scheduled and automatic triggers fire only while the server is below the start threshold; manual "Seed teď" always works (subject to cooldown, P5).
- P3-B03 · A seed run posts one message in the seed channel, pings the Seed role at most once per protection window (otherwise posts without ping), and edits the same message every 60 s with progress.
- P3-B04 · At the live threshold the run ends: the message becomes "Server je živý" (or is deleted), no further pings, panel progress disappears.
- P3-B05 · A run ends after the max duration even below the threshold ("Nedosáhl hranice … ukončen").
- P3-B06 · Admin control message in a private channel (one message for all servers) with per-server Seed buttons and panel refresh/pause; only Logi admins may use it, others get a private refusal.
- P3-B07 · Seed history per server (30 days): start, trigger/actor, players at start → end, result, duration, pinged count or protection reason; average time to live.
- P3-B08 · Seed actions are available on the web ("Seed teď") and Discord with the same permission (Logi admins).
- P3-B09 · `/api/v1` parity: the seed plan is exposed in `GET/PATCH clan/settings` with OpenAPI; "seed now" is a documented exclusion (live Discord action) (spec `docs/superpowers/specs/2026-10-05-discord-redesign-design.md`).

## 3. Owner decisions applied

- **SEED is for admins only**: "Ovládání serveru" message in a private admin channel + the Logi web; **no seed button on the public panel** (seed question Varianta B; A "SEED on the public panel" and C "web only" are "varianta, nevybráno").
- Triggers manual, schedule or automatic; posts to the seed channel and tags an opt-in Seed role; cooldown between seeds; edits the call to "Server je živý" at the threshold.
- Live at 40+ players; seed starts under 20.
- Conflicts with P5 to resolve (INDEX): P5 says "Mezi seedy jsou aspoň 2 hodiny" and the role button "Zvát mě na seed" with one control message per server; P3 shows ping protection 4 h, button "Odebírat výzvy" and one control message for all servers.

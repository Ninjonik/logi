## 2. Behaviour and data

- D5-B01 · The roster message variant (photo + text / photo only) is chosen per publish; its default comes from Zprávy a panely → Soupiska (N1-11) and is "Fotka a text".
- D5-B02 · First publish offers mentions of rostered players (default on) and no DM/changes options.
- D5-B03 · Re-publish edits the same Discord message (no new message) and posts the change summary under it; DMs go only to affected players.
- D5-B04 · The diff is computed against the last published version (added, removed → reserves/out, moved squad, role change) with counts.
- D5-B05 · Mentions default off on re-publish.
- D5-B06 · Counters of rostered players, reserves and non-attending players are shown before publishing.
- D5-B07 · The target channel comes from Kanály a jazyk (per game) and is read-only here.
- D5-B08 · The roster publish default is exposed in `/api/v1` `GET/PATCH clan/settings` with OpenAPI (spec `docs/superpowers/specs/2026-10-05-discord-redesign-design.md`); per-publish options (variant, mentions, DM, changes post) need an API path or an explicit exclusion in `configuration-coverage.md` (the spec lists none for them).

## 3. Owner decisions applied

- **Roster message defaults to variant A (photo + text)**; **variant B (photo only) is "varianta, nevybráno" as default** but selectable at publish time (D5-05, D5-15).
- Buttons on the roster message: "Zobrazit zařazení", "Zobrazit soupisku" (private, by squad), "Otevřít soupisku" (DECISIONS). The D5 preview shows only two of them (simplified); L1-102 and the spec `docs/superpowers/specs/2026-10-05-discord-redesign-design.md` (three buttons, "Zobrazit soupisku" with confirmation ticks) are authoritative.

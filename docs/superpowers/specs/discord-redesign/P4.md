## 2. Behaviour and data

- P4-B01 · Panel states: Živě (≥1 player, fresh), Prázdný (0 players), Seedujeme (seed running, below 40), Nedostupný (server/CRCON not answering, last data time), Pozastaveno (admin paused).
- P4-B02 · Refresh every 60 s for all live panels; footer shows relative update time and interval.
- P4-B03 · HLL fields: map, mode, day/night, players/max, queue (if reported), time remaining, allied/axis sector score, next map, per-player kills/deaths.
- P4-B04 · Wardogs fields: three factions with points, map, players; per-player kills and current cash.
- P4-B05 · Live threshold 40 players; seed progress bar of 10 segments towards the threshold.
- P4-B06 · Password shown only in a channel @everyone cannot view, re-checked every refresh; auto-removed + errors-channel notice when the channel becomes public.
- P4-B07 · Clan-only panel: running Logi match line and "Z klanu hraje" (players matched via linked Steam) only when available.
- P4-B08 · Combined panel: public data only, per-row join buttons, each server still has its own panel.
- P4-B09 · Player list: private, current round only, sorted by kills, 8 per page, split by side/faction.
- P4-B10 · Join page: http(s) link → `steam://connect/<ip:port>` with manual fallback and copy; Wardogs shows the join code; never a password.
- P4-B11 · No Seed button on any public panel.

## 3. Owner decisions applied

- One panel per server: "Vlci #1 · Public" → public channel; "Vlci #2 · Trénink a zápasy" → private clan channel; optional combined "Naše servery".
- Refresh every 60 s; live at ≥40 players; seed under 20.
- Private training panel shows the password only where @everyone cannot see; hidden automatically if the channel becomes public.
- Joining: IP:port (HLL) and join code (WD) + "Připojit se" via `logi.app/join`.
- SEED for admins only (seed Varianta B); public panel has no seed button.
- Default graphics style **A (generated image)** for HLL and Wardogs panels (P7/P8); these text frames are what sits under the image.

- Every item is checked in Discord with the clan language set to `cs`. "Card" means a Components V2 container with the clan accent bar on the left (default `#E8A33D`).

## 1. Elements

### 1.0 Board-wide rules (header)

- L1-01 · The announcement in `#oznameni` is a single message from announcement to result; the bot edits it in place and never posts a second one for a state change.
- L1-02 · The state is shown as a chip inside the card; the accent bar is always the clan colour, whatever the state or category.
- L1-03 · The server password reaches only rostered players, in the private "Moje zařazení" reply; it never appears on the public card, forum post, scheduled event or calendar link.
- L1-04 · Buttons are verbs: "Přihlásit se", "Upravit přihlášku", "Nepřijdu", "Přidat do kalendáře", "Zobrazit zařazení".
- L1-05 · Times are short Discord timestamps with weekday plus relative time where useful, e.g. "ne 11. 10. · 20:00 · za 6 dní"; Discord renders them in the reader's time zone.
- L1-06 · A team is shown as its short code chip or logo ("VLK", "ROG"); a side carries its faction emblem ("Spojenci" ★, "Osa" ✚). No coloured squares.
- L1-07 · The match category is a chip next to the title ("Přátelák"); the category colour appears only as the chip's dot.
- L1-08 · Copy uses "ty"; no internal markers, custom IDs or record IDs are visible.
- L1-09 · State chip vocabulary (dot colour): "Přihlášky otevřené" (green), "Přihlášky uzavřené" (grey), "Soupiska zveřejněna" (blue), "Začíná" (amber), "Hraje se" (green), "Odehráno" (grey), "Zrušeno" (red).

## 2. Behaviour and data

- L1-B01 · One managed message per event and channel; every state change edits it (same message ID); a deleted message is re-created in place.
- L1-B02 · Role ping (clan role or template roles) only on create; edits never re-ping.
- L1-B03 · Card state machine: Přihlášky otevřené → (Skupina plná) → Přihlášky uzavřené → Soupiska zveřejněna → Začíná → Hraje se → Odehráno; "Zrušeno" when the event is concluded before the meeting time.
- L1-B04 · Button sets per state: open 5 (sign-up, edit, decline, attendees, calendar); closed 2; roster published 4; starting 3; playing 0; played 1 link; cancelled 0.
- L1-B05 · Choosing a full capped group stores the sign-up as reserve without group, and the card names the full groups.
- L1-B06 · A group can require a Discord role; the reply names the group and the role.
- L1-B07 · Password only in "Moje zařazení" for squad players and reserves; never in public messages, forum, scheduled event or calendar.
- L1-B08 · "Potvrdím účast" is available only from the meeting start; "Přijdu později" earlier.
- L1-B09 · "Zobrazit přihlášené" is usable by everyone; admins (Logi admin role, fresh check) additionally see reasons, "Bez odpovědi" and the two admin buttons.

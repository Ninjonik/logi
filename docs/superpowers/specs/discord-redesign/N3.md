## 2. Behaviour and data

- N3-B01 · Per-command settings stored per workspace: enabled, allowed group (+ extra roles), reply mode, allowed channels.
- N3-B02 · Saving triggers command re-registration; the page shows the last registration time and count.
- N3-B03 · "Znovu zaregistrovat" requests an immediate re-registration from the bot.
- N3-B04 · Disabled command: the bot answers with a short explanation; `/help` omits it.
- N3-B05 · Channel restriction: outside allowed channels the bot replies where the command works.
- N3-B06 · `/close_ticket` and `/close_application` follow the Tickety/Členství enabled state (not separately toggleable).
- N3-B07 · "(pro správce)" suffix added only to commands restricted to Logi admins.
- N3-B08 · Descriptions registered in the clan language; language change re-registers.
- N3-B09 · Legacy stats connections can be converted into Game servers with encrypted keys.
- N3-B10 · `/api/v1` parity: command settings are exposed in `GET/PATCH clan/settings` with OpenAPI; re-registering commands is a documented exclusion (live Discord action) (spec `docs/superpowers/specs/2026-10-05-discord-redesign-design.md`).

## 3. Owner decisions applied

- New `/help`; `/player` private with Sdílet; staff commands visible to everyone, permission checked when used; clan language.

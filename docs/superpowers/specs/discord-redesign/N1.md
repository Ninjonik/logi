### 1.4 Design note (behaviour, not rendered on the page)

- N1-46 · "Kanály a jazyk" keeps language, time zone, Oznámení and Informace o akci, forum categories, voice-channel category and meeting channel, all with per-game exceptions.
- N1-47 · "Zprávy a panely" owns the errors channel; Kalendář and Chyby bota leave "Kanály a jazyk" (errors → here, calendar → Panely v Discordu).
- N1-48 · "Panely v Discordu" owns the channels of all panels (live servers, Naše servery, Ovládání serveru, results, WD League, Kalendář).
- N1-49 · "Wardogs League" keeps only the input channel for match links; separate league cards end; the league is shown by the WD League panels.
- N1-50 · Členství, Tickety, Příkazy keep their panels, threads and Share channel; they are only shown here.
- N1-51 · `calendarCategories`: keep; it is the Kalendář panel's category filter and the bot selects events by it.
- N1-52 · Per-game `forumCategoryId` and `meetingChannelId`: keep; the bot creates the forum and scheduled event according to the match's game.
- N1-53 · `collectSpecialization`: keep as a per-category option "ptát se na specializaci" (HLL only); the wizard skips the step when the category does not want it; the clan-wide field is converted to categories.
- N1-54 · Panel kind `scoreboard`: merged into Živé skóre (switch "Skóre frakcí" in the editor); Results do not offer options they ignore.
- N1-55 · Per-panel faction emoji: moved to the clan-wide "Znaky frakcí" so factions look the same everywhere.

## 2. Behaviour and data

- N1-B01 · Clan accent default `#E8A33D`, applied by every bot message (announcements, panels, DMs, command replies); system errors use grey.
- N1-B02 · Icon density applies to all messages, not only announcements.
- N1-B03 · One clan-wide faction-sign set used in announcements, results, panels and `/stats`.
- N1-B04 · Every channel is edited on exactly one page; locked rows link to the owning page.
- N1-B05 · Roster message default variant (Fotka a text / Jen fotka) is stored here and pre-selects the publish dialog.
- N1-B06 · Toggle defaults: roster-change post on, debrief on, absence posts off, scheduled event on, recap on, training result on, roster-change DM on, application-close DM on, ticket-close DM on.
- N1-B07 · Every message row has a rendered preview ("Náhled") using the shared renderer.
- N1-B08 · Panel rows reflect live panel status (chips "Chyba", "Neodesláno", "Pozastaveno") from P1.
- N1-B09 · Save bar collects all changes on the page into one save.
- N1-B10 · `/api/v1` parity: message settings (accent, icons, toggles, roster default) are exposed in `GET/PATCH clan/settings` with OpenAPI (spec `docs/superpowers/specs/2026-10-05-discord-redesign-design.md`).

## 3. Owner decisions applied

- One clan accent; event categories as chips; clan language for all messages.
- **Roster message default = "Fotka a text" (variant A)**; "Jen fotka" (variant B) remains selectable at publish (D5).
- **Late/absent notices in the match thread: optional, off by default, never with the reason** (N1-15 switch off).
- Panels are managed on "Panely v Discordu" (P1); this page only lists them.
- Note: N1-37 says the recruitment panel button is "Přihlásit se do klanu", while L4/L6 use "Podat přihlášku" (see INDEX conflicts).
